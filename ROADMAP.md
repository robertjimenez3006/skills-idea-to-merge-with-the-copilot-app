# Mona's Bookmark Roadmap

A focused plan for making Mona's Bookmark Manager easier to organize, update, and trust.

| Area | Item | Type | Priority |
|---|---|---|---|
| Discovery | Search and filter bookmarks | 🚀 Feature | P1 |
| Maintenance | Edit a saved bookmark | 🚀 Feature | P1 |
| Organization | Add tags or folders | 🚀 Feature | P2 |
| Portability | Import and export bookmarks | 🚀 Feature | P2 |
| Reliability | Prevent duplicate slugs | 🐞 Risk | P2 |
| Validation | Reject empty URLs | 🐞 Risk | P1 |
| Data safety | Bookmarks can be lost when localStorage is cleared | 🐞 Risk | P1 |

## 🚀 Planned features

- 🚀 Search and filter bookmarks — [P1]
- 🚀 Edit a saved bookmark — [P1]
- 🚀 Organize bookmarks with tags or folders — [P2]
- 🚀 Import and export bookmarks — [P2]

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs could make saved links ambiguous — [P2]
- 🐞 Empty URLs must be rejected before saving — [P1]
- 🐞 Clearing browser localStorage can erase saved bookmarks — [P1]
